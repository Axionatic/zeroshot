# Upstream v6.46 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish an upstream-identical two-parent baseline and port the fork's approved identity, publication, sandbox, reachability, iteration, and terminal-lifecycle foundations.

**Architecture:** Build from the pinned upstream commit and join history with an `ours` merge. Make narrowly tested adaptations in current upstream sources, retaining release dry runs and upstream runtime ownership while adding internal publication guards and the selected security/lifecycle fixes.

**Tech Stack:** Git worktrees, Node.js 22, TypeScript/CommonJS, Mocha, GitHub Actions YAML, `js-yaml`, Rust/Cargo.

**Spec:** `docs/superpowers/specs/2026-09-02-upstream-v6.46-reconciliation-design.md`

## Global Constraints

- Pin upstream to `e73727662df53bbaf8aad8ba9e489d2c76a79499`, fork tip to `1bc71f6881da82de9f28dc5c78107a9151ed24c0`, and shared base to `3077e372746e3897b3e89dd99dabab20ed7dceb7`.
- The bridge tree must be byte-identical to upstream and report `79 0` against `upstream/main`.
- Preserve upstream package identity and dry-run topology, but guard all public mutation jobs with `github.repository == 'the-open-engine/zeroshot'`.
- Keep Node active; build/test but do not install or activate Rust/native, hosted target, protocol, or Python products.
- Never hand-edit generated `lib/` or protocol projections.
- Do not run a live provider, push, merge shared `main`, publish, or add release credentials.

describe('internal release policy', function () {

    it(`${filename} guards every mutating job by canonical repository`, function () {
      const source = fs.readFileSync(
        path.join(__dirname, '../../.github/workflows', filename),
        'utf8'
      );
      const workflow = yaml.load(source);
      for (const jobName of jobs) {
        const condition = String(workflow.jobs[jobName].if || '');
        assert.match(condition, /github\.repository\s*==\s*'the-open-engine\/zeroshot'/);
      }
    });
  }

  it('guards newly added publishing primitives too', function () {
    const primitive =
      /npm publish|cargo publish|gh release (create|upload)|docker push|pypa\/gh-action-pypi-publish|release-python\.yml/;
    for (const filename of Object.keys(GUARDED)) {
      const workflow = yaml.load(
        fs.readFileSync(path.join(__dirname, '../../.github/workflows', filename), 'utf8')
      );
      for (const [jobName, job] of Object.entries(workflow.jobs)) {
        if (!primitive.test(JSON.stringify(job))) continue;
        assert.match(
          String(job.if || ''),
          /github\.repository\s*==\s*'the-open-engine\/zeroshot'/,
          `${filename}:${jobName}`
        );
      }
    }
  });
});

- [ ] **Step 5: Add bounded synthesis and idempotent terminalization**

  agent.terminalPhase = { state: 'synthesizing', reason, deadlineAt: Date.now() + deadlineMs };

}

agents without a synthesis operation retain upstream failure behavior. Never
install a ten-minute cluster-wide timer.
